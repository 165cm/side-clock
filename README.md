# 🕐 Side Clock

フルスクリーン中に時計と天気をニュース番組のショルダー風に表示するChrome拡張機能です。

![Chrome](https://img.shields.io/badge/Chrome-Extension-4fc3f7?logo=googlechrome&logoColor=white)
![Manifest](https://img.shields.io/badge/Manifest-V3-4fc3f7)
![License](https://img.shields.io/badge/License-MIT-4fc3f7)

---

## 機能

- **リアルタイム時計** — 24時間 / AM PM 切替対応、等幅フォントで数字がブレない
- **天気表示** — 現在地の天気と気温を自動取得（°C / °F 切替可）
- **60秒リングアニメーション** — 外枠を1分で一周する水色のプログレスリング
- **ドラッグ移動** — 上部の取っ手（⠿ ⠿）をドラッグして自由に配置
- **ワンクリック角移動** — 4隅の水色三角タブをクリックして瞬時に移動
- **自動フィット** — オーバーレイ幅に合わせて文字サイズを自動調整（はみ出し防止）

## インストール

### Chrome ウェブストアから（推奨）

> *審査中のため、近日公開予定*

### 手動インストール（開発者向け）

1. このリポジトリをクローンまたはZIPでダウンロード
   ```
   git clone https://github.com/165cm/side-clock.git
   ```
2. Chrome で `chrome://extensions` を開く
3. 右上の **「デベロッパーモード」** をオンにする
4. **「パッケージ化されていない拡張機能を読み込む」** をクリック
5. ダウンロードした `side-clock` フォルダを選択

## 使い方

インストール後、任意のページで自動的にオーバーレイが表示されます。

| 操作 | 方法 |
|---|---|
| 移動する | 上部の **⠿ ⠿** をドラッグ |
| 角にスナップ | 4隅の **水色三角タブ** をクリック |
| 設定を変える | ツールバーの拡張機能アイコンをクリック |

### 設定項目

| 設定 | 内容 |
|---|---|
| 有効 / 無効 | オーバーレイの表示・非表示 |
| 天気表示 | 天気と気温の表示切替 |
| 温度単位 | °C / °F |
| 時刻フォーマット | 24時間表示 / AM PM |

## プライバシー

- 取得する情報：**位置情報（緯度・経度）のみ** — 天気表示目的に限定
- 個人情報・閲覧履歴・行動データは一切収集しません
- 設定はブラウザのローカルストレージに保存されます
